# e-shipにログイン

<div class="point-box" markdown="1">
本項ではe-shipのログインについてご説明します。  
ログイン後はパスワードの保存を行っても問題ありません。
</div>

<div class="point-box point-box--red" markdown="1">
<div class="point-box__title">🚨 ログイン必須の理由</div>
<span class="red-text">
e-shipに正しくログインができていないと、リサーチサポートツールの拡張機能が動作しないためご注意ください。拡張機能については次項「各種拡張機能導入」で詳しく解説しています。
</span>
</div>

---

## e-shipログイン手順

<div class="step-card" markdown="1">
<div class="step-header">
  <span class="step-number">STEP 01</span>
  <span class="step-title">Gmailでe-shipの招待メールを確認する</span>
</div>

e-shipの招待メールを確認し、「アカウント有効化」をクリックしてください。

![招待メール確認](images/env_eship_login.md/eh1.png)
</div>

<div class="step-card" markdown="1">
<div class="step-header">
  <span class="step-number">STEP 02</span>
  <span class="step-title">認証メール再送信画面について</span>
</div>

画像のように「認証メール再送信」の画面になっている場合でも、アカウント申請は完了している状態です。  
そのまま「ログイン」ボタンを押してスキップしてください。

![認証メール再送信画面](images/env_eship_login.md/eh2.png)
</div>

<div class="step-card" markdown="1">
<div class="step-header">
  <span class="step-number">STEP 03</span>
  <span class="step-title">ログイン情報の入力</span>
</div>

ご自身のGmailアドレスと、共通パスワード「**e-shipresearch**」を入力し、「ログイン」をクリックしてください。

![ログイン情報入力](images/env_eship_login.md/eh3.png)
</div>

<div class="step-card" markdown="1">
<div class="step-header">
  <span class="step-number">STEP 04</span>
  <span class="step-title">ログイン後画面の確認</span>
</div>

下記のようなページになり、「ログインしました」と表示されていればログイン完了です。

![ログイン完了画面](images/env_eship_login.md/eh4.png)
</div>

---

## ログインできない場合

<div class="point-box point-box--yellow" markdown="1">
<div class="point-box__title">⚠️ ログインができない場合の確認事項</div>
次のような場合は、作業を止めて管理者へご連絡ください。

- 招待メールが届いていない  
- パスワードを入力してもログインできない  
- 画面が正常に表示されない  
</div>

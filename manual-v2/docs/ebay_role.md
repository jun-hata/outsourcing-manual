# eBayについて（運営方法とリサーチ担当の役割）

## 当ショップの運営方法

当ショップでは、**無在庫販売**という販売方法を採用しています。

無在庫販売とは、商品を事前に仕入れて在庫として持つのではなく、商品が売れてから国内ショップなどから仕入れて発送する販売方法です。

当ショップの販売は、主に以下の流れで行われています。

<div class="step-card" markdown="1">
<div class="step-header">
  <span class="step-number">CYCLE</span>
  <span class="step-title">ショップ全体の販売サイクル</span>
</div>

- **① 商品をリサーチ**（← 今回担当していただく業務です！）  
- **② eBayへ出品**  
- **③ 商品が売れたら国内ショップから仕入れ**  
- **④ お客様へ発送（海外発送）**  
</div>

## リサーチ作業の流れと報酬の発生

実際のリサーチ業務は、主に以下の流れで進めていただきます。  
作業を進めてスプレッドシートに入力することで、段階に応じて報酬が発生します。

<div class="step-card" markdown="1">
<div class="step-header">
  <span class="step-number">FLOW</span>
  <span class="step-title">作業の流れと報酬の発生</span>
</div>

- **① リサーチ対象リストの確認**  
  共有されたスプレッドシートからリサーチ対象の商品を確認します。

- **② リサーチの実施**  
  eBayの最安値確認、国内仕入れ先の特定、AIツールを使った重量・送料判定を行います。

- **③ スプレッドシートへ入力**  
  リサーチ結果をスプレッドシートに記入して1件の作業が完了します。

- **💰 ④ リストアップ報酬の発生**  
  **1件の入力完了につき 60円** の報酬が発生します。

- **🎁 ⑤ インセンティブ報酬の発生**  
  入力した商品が実際にeBayで販売された場合、**販売利益の10％** が成果報酬として追加還元されます。
</div>

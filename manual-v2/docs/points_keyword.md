# 検索キーワードについて

<div class="point-box" markdown="1">
<span class="marker-yellow">リサーチで一番失敗しやすいポイントは、最安値を見誤ること</span>です。  
リサーチの精度は「検索キーワード」の選定によって大きく変わります。

本ページでは、役割が異なる2つの検索キーワードについて解説します。

1. **アクティブ検索（eBay側）**：現在の市場価格とライバルの出品状況を見るための検索
2. **国内仕入れ検索（仕入れ先側）**：安く仕入れられる商品を見つけるための検索
</div>

---

## ① アクティブ検索の検索キーワード

アクティブ検索は「現在の市場価格と競合状況を見るための検索」です。  
最も重要なルールは、<span class="marker-yellow">「余計なワードを入れないこと」</span>です。

### 基本構造

基本は **「ブランド名 + 型番」** の2〜3単語程度で検索します。

```text
SONY NW-A306
```

検索結果が広すぎて無関係な商品が多く混ざる場合は、3〜4単語程度に調整します。

```text
SONY NW-A306 32GB
```

#### ⚠️ やってはいけない検索例（ワードの入れすぎ）

```text
SONY NW-A306 Digital Audio Player 32GB Black
```

このようにワードを増やしすぎると、「Digital」とタイトルに明記していない出品者や、「Audio Player」と書いていない出品者が検索結果から除外されてしまいます。  
本来確認すべきライバルセラーが表示されなくなり、正しい最安値・市場価格を把握できなくなるため注意してください。

### 検索の手順

1回の検索結果だけで判断せず、<span class="marker-yellow">必ずキーワードを変えて3回は検索</span>してください。

- **1回目**：2〜3単語（ブランド＋型番）で基本検索
- **2回目**：少し条件を広げて検索
- **3回目**：必要に応じて補足キーワードを1語足して検索

複数回検索することで、検索漏れや価格帯の誤認を確実に防ぐことができます。

### 例外：英語のタイトル・作品名の場合

アニメやゲームなどのタイトルは、英単語が複数並ぶ固有名詞があります。

```text
Attack on Titan （進撃の巨人）
Weathering with You （天気の子）
```

このような固有名詞の場合は、全体で1つの単語として扱って問題ありません。  
なお、日本の作品であっても日本語の直訳ではなく、必ず<span class="red-text">米国向けの正式名称（英語タイトル）</span>で検索してください。

### アクティブ検索の重要な考え方

アクティブ検索は「今の市場全体の状況」を見るための検索です。  
最初から細かく絞り込みすぎると、特殊な出品や一部の価格帯しか見えなくなってしまいます。まずは最小限のキーワードで検索し、市場全体の相場感を把握することを意識しましょう。

## ② 国内仕入れの検索キーワード

国内検索は、メルカリ・ヤフオク・ECサイトなどから「仕入れ対象を見つけるための検索」です。

仕入れ先は探しても無い時は無いので、<span class="marker-yellow">仕入れ商品の検索であまり時間をかけないように注意しましょう</span>。各サイト、Google検索でキーワードを変えながら２巡程度で問題ありません。

### 「表記ゆれ」への対応

同じ商品であっても、出品者によってタイトルの付け方が異なります。このように書き方が複数存在することを「表記ゆれ」と呼びます。

```text
NW-A306
NWA306
NW A306
A306
A-306
```

フリマサイトや出品者によって、型番が省略されていたり、スペースの有無が異なったりするケースが非常に多くあります。

### 国内検索の基本戦略

安く出品されている商品を取りこぼさないために、以下のバリエーションで検索ワードを試してください。

- **型番のみで検索**（例：`NW-A306`）
- **ブランド ＋ 型番で検索**（例：`SONY NW-A306`）
- **型番を一部省略して検索**（例：`A306`）
- **日本語商品名・通称で検索**（例：`ソニー ウォークマン`）
- **英語表記・カタカナ表記を切り替えて検索**

```text
SONY NW-A306
ソニー A306
ウォークマン A306
NW A306
```

完全固有の型番（例：`DSC-RX100M7`、`ATH-CK1TW` など）がある商品は、型番単体で検索するのも非常に有効です。  
アクティブ検索と同様に、**キーワードを変えながら複数回検索すること**が安く仕入れるコツです。

### 型番に含まれるカラー・機能コードに注意

機械や電化製品の型番には、末尾にカラーコードや機能コードが含まれている場合があります。

| コード | 意味 |
| :--- | :--- |
| **BK** | Black（ブラック） |
| **WH** | White（ホワイト） |
| **BL** | Blue（ブルー） |
| **RD** | Red（レッド） |
| **ANC** | アクティブノイズキャンセリング |
| **NC** | ノイズキャンセリング |

型番がほとんど同じに見えても、末尾のアルファベットが1文字違うだけで「色違い」や「性能違い（別モデル）」の可能性があります。  
リサーチ時は、アルファベットの末尾まで完全に一致しているか必ず確認してください。

## まとめ

| 検索の種類 | 目的 | 意識するポイント |
| :--- | :--- | :--- |
| **🎯 アクティブ検索** | 市場価格・最安値の把握 | **精度重視**（余計なワードを入れず最小単語で検索） |
| **🔍 国内仕入れ検索** | 仕入れ商品の発見 | **発見重視**（表記ゆれや通称を試して幅広く探す） |

目的によって検索の考え方が大きく異なります。この違いを意識してリサーチを行うことで、作業の精度とスピードが大幅に向上します。

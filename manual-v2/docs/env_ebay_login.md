# ebayのアカウント作成

<div class="point-box" markdown="1">
外注スタッフとして作業を開始するまでに必要な2つの手順を説明します。

1. **① eBayアカウントの新規作成**
2. **② MUAA（マルチユーザー・アカウントアクセス）への参加**

この2つが完了すると、依頼者のアカウントに安全にアクセスし、テラピークを使ったリサーチ作業が行えるようになります。
</div>

---

## MUAAとは

<div class="point-box point-box--green" markdown="1">
<div class="point-box__title">💡 安全な作業連携の仕組み（MUAA）</div>
MUAA（Multi-User Account Access / マルチユーザー・アカウントアクセス）とは、eBayが公式に提供しているアカウント共有機能です。

通常、依頼者のアカウントで作業するにはIDとパスワードが必要ですが、それを教えてもらうのはお互いにとってセキュリティ上のリスクがあります。MUAAを使うと、依頼者からの招待を承認するだけで、**自分のアカウントでログインしながら依頼者のアカウント上で作業ができるようになります。** お互いの個人情報は見えない仕組みになっているので、安心して作業を進めることができます。

そのため、このMUAAを利用するには**自分専用のeBayアカウントが必要**です。
</div>

## ① eBayアカウントの作成

### 事前に準備するもの

<div class="example-box" markdown="1">
- **メールアドレス**（[作業開始準備② 必要情報の送信](required_info.md)で管理者に送ったGmailアドレス以外で作成する方は、その旨を管理者に伝えてください。）  
- **スマートフォン**（SMS認証用）  
- **氏名**（英語表記）
</div>

### 作成手順

<div class="step-card" markdown="1">
<div class="step-header">
  <span class="step-number">STEP 01</span>
  <span class="step-title">eBay公式サイトにアクセスする</span>
</div>

[https://www.ebay.com](https://www.ebay.com) にアクセスします。  
ページ右上の言語設定が「**English**」になっていることを確認し、日本語になっている場合は「English」に切り替えてください。
</div>

<div class="step-card" markdown="1">
<div class="step-header">
  <span class="step-number">STEP 02</span>
  <span class="step-title">Registerをクリックする</span>
</div>

ページ左上の「**Register**」をクリックします。
</div>

<div class="step-card" markdown="1">
<div class="step-header">
  <span class="step-number">STEP 03</span>
  <span class="step-title">アカウントの種類を選択する</span>
</div>

「**Personal account（個人）**」を選択します。
</div>

<div class="step-card" markdown="1">
<div class="step-header">
  <span class="step-number">STEP 04</span>
  <span class="step-title">必要情報を入力する</span>
</div>

以下の情報を入力し、「**Create account**」をクリックします。

- First name（名）  
- Last name（姓）  
- メールアドレス  
- パスワード
</div>

<div class="step-card" markdown="1">
<div class="step-header">
  <span class="step-number">STEP 05</span>
  <span class="step-title">メールアドレスを認証する</span>
</div>

登録したメールアドレスに確認メールが届きます。  
メール内の「**Confirm your email**」をクリックするか、認証コードを入力してアカウントを有効化してください。
</div>

<div class="step-card" markdown="1">
<div class="step-header">
  <span class="step-number">STEP 06</span>
  <span class="step-title">住所登録の案内について</span>
</div>

「Create account」をクリックしてアカウントが作成されると、住所登録の案内画面に移ることがあります。  
この作業はアカウント作成後に Account settings からいつでも行えます。  
テラピークを使ったリサーチ作業のみを行う場合は住所登録は不要ですので、スキップして問題ありません。
</div>

## ② MUAAへの参加手順（作業者側）

<div class="point-box point-box--red" markdown="1">
<div class="point-box__title">🚨 アカウント作成完了後の必須連絡</div>
<span class="red-text">
この手順を始める際は、アカウント作成が完了したことをチャットワークから管理者に連絡してください。  
招待メールの有効期限は送信から24時間です。期限が切れた場合は依頼者に再送信を依頼してください。
</span>
</div>

### 参加手順

<div class="step-card" markdown="1">
<div class="step-header">
  <span class="step-number">STEP 01</span>
  <span class="step-title">招待メールを開く</span>
</div>

依頼者からeBay経由で招待メールが届くので開きます。
</div>

<div class="step-card" markdown="1">
<div class="step-header">
  <span class="step-number">STEP 02</span>
  <span class="step-title">Accept inviteをクリックする</span>
</div>

メール本文内の「**Accept invite**」をクリックします。
</div>

<div class="step-card" markdown="1">
<div class="step-header">
  <span class="step-number">STEP 03</span>
  <span class="step-title">自分のeBayアカウントでログインする</span>
</div>

①で作成した自分のeBayアカウント（メールアドレスとパスワード）でログインします。
</div>

<div class="step-card" markdown="1">
<div class="step-header">
  <span class="step-number">STEP 04</span>
  <span class="step-title">2段階認証を設定する</span>
</div>

「**SMS（テキストメッセージ）**」を選択し、電話番号を入力して「**Send**」をクリックします。  
SMSで届いた認証コードを入力してください。

続いてメールアドレスの認証を求められる場合は、「**Send code**」をクリックし、メールで届いたコードを入力します。
</div>

<div class="step-card" markdown="1">
<div class="step-header">
  <span class="step-number">STEP 05</span>
  <span class="step-title">招待を承諾する</span>
</div>

2段階認証の設定完了後、再度招待メールを開いて「**Accept invite**」をクリックし、確認画面で「**Accept**」をクリックして承諾します。
</div>

<div class="step-card" markdown="1">
<div class="step-header">
  <span class="step-number">STEP 06</span>
  <span class="step-title">依頼者のセラーハブにアクセスする</span>
</div>

自分のアカウントで [https://www.ebay.com](https://www.ebay.com) にログインし、以下の順で進みます。

1. 左上のアカウント名をクリック（「**Hi ●●**」と書かれている場所）→「**Account Preferences**」項目下の「**Team access**」をクリック  
2. 使用したいアカウントの横にある「**I'd like to**」と書かれたドロップダウンを選択し、「**Go to Seller Hub**」を選択してください。  

依頼者のセラーハブ画面に入ったら、**画面左上のアカウント名が自分の名前**であることと、**セラーハブ内のアカウントが管理者アカウント名**であることを確認してください。
</div>

### テラピークでリサーチを開始する

<div class="point-box point-box--green" markdown="1">
セラーハブ上段メニューの「**Research**」→「**product research**」を選択し、調べたい商品のキーワードを入力して検索します。

👉 [テラピークとは](tool_terapeak.md)
</div>

## うまくいかない場合

<div class="point-box point-box--yellow" markdown="1">
<div class="point-box__title">⚠️ トラブル時の対応</div>
次のような場合は、作業を止めて管理者へご連絡ください。

- 招待メールが届いていない  
- 有効期限内に承諾できなかった  
- ログインができない  
- セラーハブにアクセスできない  
</div>

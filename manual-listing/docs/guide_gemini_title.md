# 02. Geminiを使ったタイトル作成テクニック（80文字調整・プロンプト集）（仮）

eBayの出品において、**タイトルは検索順位（SEO）と成約率を左右する最も重要な要素**です。

AI（Google Gemini）を使って、売れる英語タイトルを素早く作成する方法と注意点をまとめました。

---

## 1. 基本プロンプト（指示文）

仕入れ元の日本語タイトルをコピーし、Geminiに以下のように入力します。

```text
[日本語商品名を貼り付け]

あなたはebay物販のコンサルタントです。
SEOを意識し、海外のバイヤーが検索するキーワードを網羅して、この商品の売れるebay titleを80文字以内で作成してください。
```

---

## 2. 80文字制限の厳守ルール

eBayのタイトル上限は **半角80文字**（スペース含む）です。80文字を超えると出品時にエラーになるか、末尾が切れてしまいます。

### 文字数が超えてしまった場合のプロンプト例
もしGeminiの出力が80文字を超えていた場合は、以下のように指示して再調整してください：

```text
文字数が80文字を超えています。重要なキーワードを残したまま、半角80文字以内で作り直してください。文字数もカウントして教えてください。
```

---

## 3. タイトルに必ず含めるべきキーワードの優先順位

1. **ブランド名 / メーカー名**: `HORI`, `Nintendo`, `Sony`, `Bandai` など
2. **モデル名・型番**: `NSW-581A`, `CFI-ZCT1J` など
3. **商品ジャンル**: `Wireless Controller`, `Figure`, `Plush Toy` など
4. **作品名・キャラクター名**: `Animal Crossing`, `Pokemon`, `Pikachu` など
5. **対応プラットフォーム / 状態**: `Nintendo Switch`, `New`, `Japan` など

> [!TIP]
> 「Kawaii」「Cute」「Rare」「Awesome」といった主観的な単語よりも、バイヤーが実際に型番や仕様で検索する具体的な名詞を優先して詰め込むのがSEO上位表示のコツです。

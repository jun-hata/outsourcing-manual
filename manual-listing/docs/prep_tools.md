## 🛠️ 必要なツール・拡張機能一覧

出品作業では以下のツールと拡張機能を使用します。あらかじめ準備・ログインを済ませておいてください。

| ツール / 拡張機能 | 用途 | 準備状況 |
| :--- | :--- | :---: |
| **Google Chrome** | 作業用ブラウザ（指定のプロファイルを使用） | 必須 |
| **Google スプレッドシート** | リサーチ済み商品の確認、重量取得、Item IDの記入 | 必須 |
| **ebayリサーチサポートツール** | 仕入れ元（Yahoo!フリマ等）での送料・価格取得 | 必須 |
| **Buy and sell all things on eBay** | eBay上の最安値（Sold / Active）のクイック検索 | 必須 |
| **eShip（Chrome拡張機能）** | 商品情報の自動吸い上げ、利益計算、eBayへのListing転記 | 必須 |
| **Google Gemini（AI）** | 80文字以内のSEO英語タイトル作成、商品説明文作成 | 必須 |
| **メルカリ** | 高品質な商品画像の収集（新品・未使用 / SOLDから選定） | 必須 |

## 📋 作業開始前チェックリスト

作業を始める前に、以下の準備が整っているか確認してください：

- [ ] 指定されたGoogle Chromeの作業用プロファイルを開いている
- [ ] 管理用Googleスプレッドシートへのアクセス権限がある
- [ ] eBayのアカウントにログインできている
- [ ] eShip拡張機能にログインできている
- [ ] ebayリサーチサポートツールが正常に起動する
- [ ] Google Geminiが開ける状態になっている

# 05. リサーチ担当者からのフィードバック対応とコメント返信（仮）

出品作業後に、リサーチ担当者や管理者からスプレッドシート上でフィードバック（修正依頼や確認のコメント）が入る場合があります。

スムーズな連携を行うためのルールです。

---

## 1. コメントの確認方法

1. 定期的にスプレッドシートを開き、担当行に黄色や赤のコメントマーク（💬）が付いていないか確認します。
2. コメントの内容（例:「最安値がずれていました」「画像の枚数が足りないです」等）を確認します。

---

## 2. 修正対応と返信ルール

1. **修正作業の実行**:
   - 指摘された内容に従い、eBayのActive Listingを編集（Edit listing）して修正を完了します。
2. **日付入りでコメント返信**:
   - 修正が完了したら、必ずコメント欄に **「対応日」** と **「対応内容」** を記入して解決（または返信）してください。

### 返信テンプレート
```text
[10/20] 最安値の差額を確認し、出品価格を$115.00に修正完了しました。ご指摘ありがとうございます！
```

> [!TIP]
> 履歴を残すことで「誰が・いつ対応したか」がチーム全体で可視化され、トラブルを防ぐことができます。
